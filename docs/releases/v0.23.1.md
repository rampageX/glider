# Glider v0.23.1 · v2rayN 订阅兼容与状态诊断修复

这是基于 v0.23.0 的兼容性修复版；不新增代理传输协议，也不改变 LHA 调度策略。

## 修复内容

1. **兼容 v2rayN VLESS TCP 导出字段：** 允许 `headerType=none`、空 `host=` 与 `path=`，转换时移除这些不改变传输语义的默认项。HTTP 伪装、自定义 Host/Path、WS、gRPC 等非默认扩展仍不做降级转换。
2. **订阅状态精细化：** Web Status 区分“下载失败 / 解析失败 / 无可用节点 / 处理失败 / 成功”，并显示 HTTP 状态码、最近一次完整下载时间、上次成功解析时间。失败重试、有效缓存复用、原子文件更新及旧节点保护保持不变。
3. **回归测试：** 新增单行 Base64 混合订阅测试、REALITY + Vision TCP 默认字段测试，以及下载/解析/筛选失败的状态与时间测试。

## 已验证

- 同一份真实订阅可完整获取和解码，转换得到 **34 个 VLESS 节点**，明确跳过 **10 个 Hysteria2**，转发器配置校验通过；测试中没有输出或保存订阅密码、节点凭据。
- 用户 N1 的 Web Status 页面已显示“成功”、有效缓存、区域筛选后匹配 **29 个节点**、跳过 **10 个节点**。
- Go `with_utls` 全仓库测试、竞态检测和 `go vet` 通过；Windows AMD64 / Linux ARM64 静态交叉构建通过。
- VLESS 节点导入成功不等于所有服务端均已实际连接测试通过。Hysteria2、TUIC、VMess 等仍按既有策略跳过。

## 升级与回退

1. 备份旧二进制及当前 `subscription-output` 节点快照。
2. N1 / Linux ARM64 选用 **`glider_0.23.1_linux_arm64.tar.gz`**；Release 中无后缀的 `glider` 是 AMD64 v4，不适用于 N1。
3. 替换程序并重启实例；刷新 Status 页面，确认订阅结果、匹配数及节点实际连接。
4. 若需回退，停止服务并恢复 v0.23.0 二进制与备份快照。原有配置格式兼容，无需迁移缓存。
