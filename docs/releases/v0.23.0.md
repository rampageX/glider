# Glider v0.23.0 · 多协议订阅与 REALITY + Vision

## 更新亮点

- 订阅转换新增 **AnyTLS、Trojan TCP/TLS、VLESS TCP**，连同 SS/SSR 共支持五种协议。
- VLESS 新增进程内 **TLS / REALITY + Vision** 客户端，支持五种浏览器指纹与 Vision XUDP；无需外挂 Xray 或其他内核进程。
- 映射 SNI、证书校验开关和节点名称；Trojan 保留并校验 `pcs` 证书 SHA-256 指纹。
- `subscription-protocol` 可限定 LHA 的订阅候选协议；common / 实例重复配置取并集，启动恢复快照也会筛选。
- 时间值支持 **s/m/h/d/w** 及 `1h30m` 等复合写法；普通裸数字仍为秒。
- **`checktolerance` 裸数字仍为毫秒**，`1000` 与 `1s` 等价。DHCP 分钟、历史保留天数的原含义也保持不变。
- Status 节点表新增“协议”栏，代理链显示如 `TLS → WS → VLESS`。
- 更新默认中文 README、英文 README、配置示例及 `glider -h` / `-scheme` / `-example` 帮助。
- 沿用 0.22 的共享缓存、订阅标题、运行中更新、区域筛选与默认两小时失败重试。

## 常用新增写法

```ini
# 可放 common，或放单个实例；不配置则不限制
subscription-protocol=vless
# subscription-protocol=anytls,trojan
subscription-interval=2h
subscription-cache-ttl=1d
subscription-retry-interval=2h
checkinterval=1m
# 裸数字是毫秒，等价于 1s
checktolerance=1000
```

`subscription-protocol` 只筛选订阅节点，不影响手写 `forward=`、旧节点 include 及独立规则组。
修改配置需重启实例；普通订阅节点更新继续自动应用。

## 支持边界与验证

- 用户已确认 **AnyTLS、Trojan、VLESS REALITY + Vision 实机连接通过**。
- 自动测试覆盖三协议转换、本地 AnyTLS/Trojan 加密传输、独立 Xray REALITY/Vision 互通、错误认证拒绝、Vision XUDP、协议筛选/快照恢复、时间单位和 Status API。
- 吞吐、内存占用及长期稳定性继续观察；不宣称所有节点、服务端参数组合或发行架构均已实测。
- VLESS 暂不转换 WS/gRPC/XHTTP、额外 encryption 或其他 flow；Trojan/AnyTLS 暂不转换 WS/gRPC/自定义 ALPN。
- VMess、Hysteria2 等分享链接仍计数跳过；原有 SS/SSR 算法和扩展限制不变。

## 升级与回退

1. 备份现有二进制、主配置以及 `subscription-output` 指定的节点快照。
2. N1 下载 **`glider_0.23.0_linux_arm64.tar.gz`**；Release 中无后缀 `glider` 是 AMD64 v4，不适用于 N1。
3. 替换程序后按原配置启动，必要时刷新浏览器（Ctrl+F5）显示新的协议栏。
4. 回退时停止实例，恢复原二进制、配置和节点快照。回退 0.22 时应恢复原 SS/SSR 订阅配置；0.22 无法转换新协议。

源码构建务必加 `-tags with_utls`，正式构建脚本和发行包已启用。
