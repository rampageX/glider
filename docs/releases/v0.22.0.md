# Glider v0.22.0 · 原生 SS/SSR 订阅

## 本次更新

- 原生下载、解析、筛选多个 SS/SSR 订阅，支持整份 Base64、明文链接、中文名称及特殊字符。
- 每个订阅独立按优先级尝试直连/代理；支持公共 include 配置和四实例共享缓存。
- 自动生成区域 forward 文件，运行中更新节点，无需重启服务；内容相同不重写、不重置健康状态。
- 快照恢复、部分订阅失败隔离、空结果保留旧节点，兼容订阅元信息、注释及混合协议列表。
- 订阅标题与 Status 状态面板：脱敏 URL、成功/失败、检查时间、上次成功下载和下次刷新时间。
- 失败重试默认 **7200 秒（2 小时）**，不会被较短正常周期提前触发；`-verbose` 显示安全诊断。
- 缓存默认 `/tmp/.subscription-cache`，history 默认 `/tmp/.glider-history`；均可配置。

## 升级注意

- 原静态配置仍可使用。启用原生订阅时，将生成节点文件的 `include=` 替换为 `subscription-output=`，不要同时加载两次。
- 先停用对应旧订阅脚本定时任务，再切换管理方式；保留原脚本、配置和节点文件用于回退。
- 主配置的 include 现在在声明位置展开；标量后写覆盖，列表依次追加，命令行最后处理。建议公共 include 在前，实例设置在后。
- `/tmp` 重启可能清空；节点输出文件应继续保存在需要的持久路径，长期 history 可指定其他目录。
- N1 下载 **linux_arm64.tar.gz**；同页无后缀的 `glider` 是 Linux AMD64 v4，不能用于 N1。

完整配置、迁移和回退：[原生订阅说明](https://github.com/rampageX/glider/blob/v0.22.0/docs/native-subscriptions.md) · [四实例配置示例](https://github.com/rampageX/glider/tree/v0.22.0/config/subscription)

## 验证范围

自动测试覆盖解析、共享缓存锁、多订阅容错、取消、热更新、旧 TCP 连接延续、状态页面及重试调度。
N1 ARM64 用户已确认无旧节点文件启动和最新功能可用；不将个别仍失败的订阅服务宣称为已恢复。
其余架构提供交叉编译构建，尚未逐一实机验证。
