# Glider v0.23.3 · 可关闭 LHA 历史磁盘读写

在 v0.23.2 的基础上增加了一个明确的配置开关，避免通过设置 `/dev/null` 目录等异常路径来阻止历史持久化。

## 新增参数

```ini
# 默认 true，保存 LHA 历史；false 为彻底禁用历史文件读写
lha-history-enabled=false

# 以下参数仅在启用历史持久化时生效
lha-history-dir=/tmp/.glider-history
lha-history-retention-days=3
```

- 默认 `true`，保持过去的记录行为及默认保留 3 天。
- 设为 `false`，程序不创建历史目录、不读写历史 `.jsonl` 文件、也不会进行历史清理；以前保存的文件不删除。
- 代理、健康检查、LHA 调度、实时状态仍正常运行；Web `/lha` 历史页面及历史 API 返回空统计。
- systemd journal、程序常规日志、订阅节点快照和订阅下载缓存均不受此开关控制。
- 可写在 `glider.conf`、`include` 公共配置中，或用命令行 `-lha-history-enabled=false` 覆盖。修改配置后需重启 Glider。

## 验证

- 新增默认值、实例/common include 与 CLI 覆盖测试。
- 新增禁用时不创建目录、不产生历史文件、不删除旧历史、关闭既有 store 后不再追加记录的回归测试。
- Go 全仓 `-tags with_utls` 测试通过；多架构发布流程由 GitHub Actions 执行。

## N1 升级与回退

1. 备份当前二进制文件及配置文件。
2. 从 Release 下载 `glider_0.23.3_linux_arm64.tar.gz` 并替换 N1 运行中的 Glider。
3. 在配置文件加入 `lha-history-enabled=false`，重启对应的 systemd 实例。
4. 运行 `glider -h`，确认新参数已显示。现有旧历史文件不会自动删除；如需释放存储空间，请自行备份后清理。
5. 回退到 v0.23.2 前，先从配置文件移除 `lha-history-enabled`；旧版不能识别该项。

详细的默认参数清单：[实例配置参考模板](https://github.com/rampageX/glider/blob/main/config/subscription/instance.reference.conf.example)。
