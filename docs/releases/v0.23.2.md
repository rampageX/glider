# Glider v0.23.2 · LHA 历史记录保留策略

本版基于 v0.23.1 的稳定代码，仅调整 LHA 历史记录配置和默认保留时间；不改变代理协议、订阅转换或 LHA 调度算法。

## 更新内容

- **默认只保留最近 3 个本地自然日**（含当天），由 v0.23.1 的 30 天下调。
- 在主配置或公共 `include` 中直接使用 `lha-history-retention-days=3`。不带单位按天，支持 `3d`、`1w` 等整天单位；`0` 禁用自动清理。
- `lha-history-dir` 继续定义历史基础目录；多个实例各自使用 `glider-lha-history-<id>` 子目录。
- 继续支持 `GLIDER_LHA_HISTORY_RETENTION_DAYS` 和 `GLIDER_LHA_HISTORY_PATH` 环境变量。环境变量有效时优先于配置文件；非法天数回退到配置文件设定，不改变记录行为。
- 仅在启动和跨日时清理过期的 `YYYY-MM-DD.jsonl` 普通文件，不清理其它日志、订阅缓存或非目标文件。

## 配置示例

```ini
# 可放主配置，也可放 common include
lha-history-dir=/mnt/data/glider-history
lha-history-retention-days=3
```

相对路径以主配置文件所在目录为基准。若 systemd 中仍设置 `GLIDER_LHA_HISTORY_RETENTION_DAYS=3`，可保留；需要由配置文件完全控制时，可删除该环境变量后重启服务。

## 验证

- v0.23.2 发布前的功能变更已通过 GitHub Actions `go test -tags with_utls -v ./...` 与 GoReleaser 快照多架构构建。
- 新增默认值、配置文件/公共 include、命令行、环境变量覆盖及历史清理回归测试。
- 本版不需要修改现有订阅文件或历史目录结构。

## 更新及回退

1. 备份现有可执行文件和配置文件。
2. N1 下载 `glider_0.23.2_linux_arm64.tar.gz`（**Release 中无后缀 `glider` 并非 N1 版本**）。
3. 替换二进制，设置配置文件并重启 Glider；用 `glider -h` 检查 `lha-history-retention-days` 参数。
4. 如需回退，恢复 v0.23.1 二进制，并从配置文件移除新版特有的 `lha-history-retention-days` 参数。
